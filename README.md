# 杭州探索録3 Definitive Edition Ver.2.1

Ver.2.0の低解像度バッファ方式を完全撤廃。
画面全体を縮小→拡大する処理は一切行わず、ネイティブ解像度で描画します。

Ver.2.1では人物・窓と室内シルエット・室外機・看板・自転車・スクーター・自販機・箱・ベンチ・コーン・排水溝・屋台などを2pxグリッドのピクセル単位で再設計。
既存の斜め見下ろし投影、建物の立体構造、雨、ネオン、濡れた路面、奥行き、4地区は維持し、光や反射だけ高解像度エフェクトとして残しています。

地下鉄: 駅オブジェクトをE → 路線図 → 駅選択 → 約2秒の列車アニメーション → 到着。
NPC: 中国語のみ。Tキー/右下ボタンで日本語字幕。
L: 旅の手帳。実用中上級100語。
