# 杭州探索録3 — Ver.3.0 Production Rebuild

商品化を意識した大幅改修版。

## 操作感
従来の「キー入力＝即座に一定速度」「2フレームで脚が伸縮する」移動を廃止。
加速・減速、方向転換補間、8方向の向き、足を地面に置く歩行、腕の逆振り、
描画座標の補間、進行方向へのカメラ先読みを導入。停止・曲がり角・斜め移動を滑らかにした。

## ビジュアル
低解像度化は一切なし。ネイティブ解像度の2pxグリッドによるピクセルキャラクター。
既存の高密度な建物、室内が見える窓、室外機、配管、看板、雨、濡れた路面を維持しつつ、
遠景スカイライン、路面の微細な反射、抑えたビネットで画面構成を強化。

## ゲームシステム
地下鉄は駅オブジェクト→路線図→駅選択→約2秒の列車アニメーション→到着。
NPCは中国語のみ。Tで日本語字幕。Lで旅の手帳。
実用中上級中国語100語の収集・例文・拼音・日本語訳を収録。

GitHub Pagesでは index.html / style.css / js をすべて上書き。
